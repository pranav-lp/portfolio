I’m Pranav, an AI & Data Science student at BGSCET in Bengaluru. I like problems where a model has to do something real: keep a machine from failing, catch a fraud, read a satellite image.

Most of what I’ve built started as a 24-hour hackathon brief. I learned n8n from scratch for one of them and kept using it, and I’d rather ship something that runs than polish a slide about it.

I work mostly with agents and LLMs: React and TypeScript up front, FastAPI and Supabase behind, the Claude API doing the reasoning. Right now I’m building SNUFF and preparing Sathya Drishti for a real fine-tune.
